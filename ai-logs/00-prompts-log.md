# EduJourney / GradQuest AI Coding Prompts Log

This folder contains the AI coding prompt logs split by topic for easier review and later optimization.

## Files

- [01-overview-and-scope.md](01-overview-and-scope.md): AI assistance scope, prompt record format, and product-level prompt.
- [02-backend-data-security.md](02-backend-data-security.md): Spring Boot backend, database, auth, progress, shop, teacher, and sandbox API prompts.
- [03-frontend-state-integration.md](03-frontend-state-integration.md): Vue app shell, Pinia stores, routing, map integration, i18n, frontend API, shared UI, AI helper, tooling, and frontend tests.
- [04-game-node-html-to-vue.md](04-game-node-html-to-vue.md): The 15 game-node prompts, explicitly documenting the manual HTML prototype -> Vue conversion workflow and limited Gemini/AI assistance.
- [05-testing-docs-refinements.md](05-testing-docs-refinements.md): Testing, README/submission, iterative fix, and coverage-check prompts.

## Important Scope Note

The game nodes were primarily designed and debugged manually as standalone HTML/CSS/JavaScript prototypes. AI/Gemini assistance for those nodes was limited and mainly used for Vue conversion, cleanup, wording, payload shaping, responsiveness, and integration with the shared map/progress/i18n architecture.

For detailed node-by-node wording, use `04-game-node-html-to-vue.md`.
